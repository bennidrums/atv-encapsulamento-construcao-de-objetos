# Cadastro de Alunos e Cálculo de Médias

Atividade prática do curso **EBAC Back-end Java v2**, com foco em construtores, encapsulamento e métodos de uma classe de domínio.

## O que o programa faz

1. Pergunta quantos alunos e quantas provas serão considerados.
2. Recebe o nome de cada aluno e suas notas.
3. Valida se cada nota está entre 0 e 10.
4. Calcula e exibe a média de cada aluno.

## Conceitos praticados

- Classe `Aluno` com atributos privados.
- Construtor para inicializar o nome e a quantidade de notas.
- Métodos de instância para registrar notas e calcular média.
- Getter para consultar o nome.
- Arrays de objetos e arrays de notas.
- Laços aninhados e validação com `while`.
- Entrada de dados com `Scanner`.

## Como executar

Abra o projeto no IntelliJ IDEA e execute `src/Main.java).

## Limitações conhecidas

Os dados existem apenas durante a execução. A atividade valida a faixa das notas, mas não trata todos os cenários de entrada inválida, como quantidades negativas ou entradas não numéricas.
